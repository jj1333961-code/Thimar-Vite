# تجهيز «ثمار» للتثبيت على الكمبيوتر والأندرويد والآيفون

التطبيق الآن **PWA** كامل: له `manifest.webmanifest` وأيقونات وعامل خدمة (`sw.js`).
هذا يعني أنه قابل للتثبيت على الأنظمة الثلاثة من المتصفح مباشرة، مع واجهة تعمل دون اتصال
(النصوص تُجلب من الشبكة وتُخزَّن مؤقتًا، أما الآيات والتسميع فتظل بحاجة للاتصال أول مرة).

> **مهم:** التثبيت يعمل على **رابط منشور بـ HTTPS**. المعاينة المؤقتة (`*.style.dev`) ليست
> رابطًا دائمًا للتوزيع. انشر الموقع أولًا (زر Publish / Sites) ثم استخدم رابط النشر.

## ١) الكمبيوتر — Windows / macOS / Linux

بعد فتح رابط الموقع في Chrome أو Edge:

- **Chrome/Edge:** أيقونة التثبيت (⊕) في شريط العنوان ← «تثبيت ثمار».
- **macOS (Safari 17+):** قائمة «ملف» ← «إضافة إلى Dock».
- ستظهر أيقونة التطبيق في قائمة ابدأ / Launchpad ويعمل في نافذة مستقلة.

### نسخة سطح مكتب قابلة للتوزيع (اختياري)
مجلد `packaging/electron` يحتوي غلافًا بسيطًا يفتح التطبيق في نافذة مستقلة:

```bash
cd packaging/electron
npm install
# عدّل APP_URL في main.cjs إلى رابط النشر
npm start              # تجربة
npx electron-builder   # إنتاج مثبت Windows (.exe) أو macOS (.dmg)
```

يتطلب Node.js على جهازك، وبناء نسخة macOS يحتاج جهاز Mac.

## ٢) الأندرويد

### الأسهل: تثبيت PWA
افتح رابط الموقع في Chrome ← قائمة ⋮ ← «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية».

### حزمة APK / AAB لمتجر Google Play
استخدم `packaging/twa-manifest.json` مع أداة Bubblewrap (أو PWABuilder):

```bash
npm install -g @bubblewrap/cli
cd packaging
bubblewrap init --manifest https://YOUR-DOMAIN/manifest.webmanifest
bubblewrap build
```

قبل ذلك:
1. استبدل `YOUR-DOMAIN` في `twa-manifest.json` بنطاقك المنشور.
2. غيّر `packageId` إلى معرّفك (مثل `app.thimar.quran`).
3. أنشئ مفتاح توقيع (Bubblewrap يولّده تلقائيًا في أول بناء) واحفظه في مكان آمن.
4. ارفع ملف `assetlinks.json` على الموقع في `/.well-known/assetlinks.json` لربط التطبيق بالموقع.

> لا يوجد Android SDK أو Java في بيئة العمل الحالية، لذلك لم أبنِ ملف APK هنا؛
> الملفات والخطوات جاهزة لتشغيلها على جهازك أو عبر PWABuilder.

## ٣) الآيفون / iPad

- افتح رابط الموقع في **Safari** (ليس Chrome).
- زر المشاركة ← «إضافة إلى الشاشة الرئيسية».
- سيعمل التطبيق بملء الشاشة بأيقونة ثمار.

للنشر في App Store يلزم جهاز Mac مع Xcode وحساب Apple Developer، وتحويل الواجهة إلى
تطبيق أصلي أو استخدام غلاف WebView — وهذا خارج ما يمكن تجهيزه داخل هذه البيئة.

## ملفات التثبيت المضافة
- `public/manifest.webmanifest` — بيانات التطبيق والأيقونات.
- `public/sw.js` — عمل الواجهة دون اتصال.
- `public/icons/*` — أيقونات 192/512/maskable/apple/متجر.
- `packaging/twa-manifest.json` — قالب حزمة أندرويد.
- `packaging/electron/*` — غلاف سطح المكتب.

## ملف أندرويد الجاهز (APK)

- الملف: `artifacts/thimar.apk` — موقّع بمفتاح إصدار حقيقي وجاهز للتثبيت المباشر.
- معرّف الحزمة: `app.thimar.quran` — الإصدار 1.9.0 (مصحف التجويد الملوّن برواية حفص بنسخة الموسوعة القرآنية: 604 صفحات، خط عثماني، زخارف آيات خضراء، فاصل ذهبي ورقم صفحة، مع قائمة الآية الدائرية، إشعارات FCM، فتح المحادثة من الإشعار، إعلانات الإدارة).
- الإشعارات: انظر `packaging/android/FCM-SETUP.md`.
- يعمل كـ Trusted Web Activity على `https://thimar.freebuff.page` (وضع ملء الشاشة دون شريط عنوان عند التحقق).
- المفتاح وبيانات التوقيع: `packaging/android/thimar-release.jks` و`packaging/android/SIGNING.txt` — احتفظ بهما، فهما لازمان لكل تحديث مستقبلي.
- مشروع البناء الكامل: `packaging/android/` (Java + WebView/TWA، Gradle).

### التحقق من التوقيع
```bash
apksigner verify --print-certs artifacts/thimar.apk
```

### Digital Asset Links
يُقدَّم الملف من الـWorker على المسار `/.well-known/assetlinks.json` (لأن منصة النشر لا تسمح بمجلدات مخفية داخل الأصول).

## تشخيص تشغيل التطبيق (منذ 1.2.0)

> **1.3.0:** التطبيق يفتح الآن مباشرة داخل عرضه الداخلي (WebView) بلا متصفح ولا نافذة «فتح بواسطة»،
> وأُزيل اعتراض روابط الموقع (assetlinks) حتى تُفتح روابط ثمار في المتصفح طبيعيًا.
> للكاميرا في مكالمات الفيديو أُضيفت صلاحية CAMERA.

يسجّل التطبيق كل خطوة في الإقلاع داخل ملف خاص به على الجهاز:
- معلومات الجهاز: الشركة/الطراز، إصدار أندرويد، إصدار التطبيق، إصدار Chrome وWebView.
- المتصفحات التي تفتح `https` على الجهاز.
- حالة التحقق من النطاق (Digital Asset Links) على أندرويد 12+.
- نتيجة محاولة TWA، ومحاولة متصفح النظام، والانتقال للعرض الاحتياطي.
- أي انهيار Java مع التتبّع الكامل، وأخطاء تحميل الصفحة ورسائل JS في العرض الاحتياطي.

**كيف تفتحه:** اضغط مطوّلًا على أيقونة «ثمار» ← «تشخيص»، أو افتح الاختصار «تشخيص» من قائمة التطبيق.
داخل الشاشة: تحديث / نسخ / مشاركة / مسح. عند وجود مشكلة، انسخ السجل أو شاركه.
